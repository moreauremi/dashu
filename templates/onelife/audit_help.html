Le modèle

Un modèle est une note, ou un fichier .md, du dossier des modèles choisi dans les réglages de 1Life (un fichier se dépose par glisser-déposer dans ce dossier). Sans dossier, le modèle intégré ci-dessous sert. L'IA suit ses titres et leur ordre.

Il s'écrit en Markdown : titres de niveau 1 à 3 (#, ##, ###), listes, cases à cocher (- [ ]), tableaux et citations (>).

Les variables

Le serveur les remplace avant l'envoi, à partir de la fiche du client, de l'audit et des réglages. Une variable vide ou inconnue devient « [À compléter : nom] », et la page de l'audit la signale.

Les consignes

Une citation qui commence par « Consigne : » guide l'IA pour la partie où elle se trouve, puis disparaît du document, même si l'IA l'a recopiée :

## Recommandations

> Consigne : une recommandation par constat important, avec sa priorité.

Pas de commentaires HTML : l'éditeur de notes ne les garde pas.

Les marqueurs des notes

Facultatifs, en début de ligne dans les notes d'audit. L'IA s'en sert sans jamais en parler dans le document.

  • OP: une réponse d'Open-Prod (ce que le logiciel sait faire) ;
  • manque: une information manquante ;
  • statut: un état d'avancement ;
  • !! un point bloquant.

Les notes peuvent aussi être rangées par service, en tableaux « Besoin | Piste » : l'IA redistribue chaque élément dans le bon domaine du modèle, une seule fois.

Ce qui part chez Anthropic

Le modèle aux variables remplies et le texte des notes. Ni fichiers ni images : leurs liens restent tels quels. Le document généré est une note ordinaire, à relire et à modifier ; ce que l'IA n'a pas repris des notes s'affiche sur la page de l'audit.
